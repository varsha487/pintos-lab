---- QUESTIONS: BIOS ---- 
>> B1: What is the first instruction that gets executed?
ljmp - long jump
>> B2: At which physical address is this instruction located?
0xffff0
>> B3: Can you guess why the first instruction is like this?
ljmp stand for long jump to another location in memory for BIOS startup
>> B4: What are the next three instructions?
0xffff7: das
0xffff8: xor  (%ebx),%dh
0xffffa: das
---- QUESTIONS: BOOTLOADER ---- 
>> B5: How does the bootloader read disk sectors? In particular, what BIOS interrupt
is used?
Bootloader reads disk sectors in the read_mbr assembly code segments. Then it goes to read_sector in which we see the interrupt: int $0x13

>> B6: How does the bootloader decides whether it successfully finds the Pintos kernel?
It uses the carry flag to determine once its done iterating through the drives. Then if it didn't find the Pintos kernel, it reaches no_boot_partition.

>> B7: What happens when the bootloader could not find the Pintos kernel?
calls int $0x18 in no_boot_partition

>> B8: At what point and how exactly does the bootloader transfer control to the Pintos kernel?
it loads all the sectors by looping through them. Then, it transfers control once the kernel is loaded. The ELF header contains the start address and converts it to an offset. Then it jumps this offset. This information was listed in a comment in the loader.S file.

I put this all around an infinite while loop to take in typed input as many times as possible until "exit" is typed.
